## 4.1 疟病脉象与治则总纲 —— 不落节点

> 师曰：疟脉自弦，弦数者多热，弦迟者多寒，弦小紧者下之差，弦迟者可温之，弦紧者可发汗、针灸也，浮大者可吐之，弦数者风发也，以饮食消息止之。

整条都是脉象分型和对应治法，没有症状/方剂三元组，**不落节点**（与第二篇那几条病机治则条同样处理）。

## 4.2 疟母 + 鳖甲煎丸

> 病疟以月，一日发，当以十五日愈；设不差，当月尽解；如其不差，当云何？师曰：此结为症瘕，名曰疟母，急治之，宜鳖甲煎丸。

### 新证候 `nue_mu` 疟母

- needs：`periodic_chill_fever.yes + hypochondriac_mass.yes`
- 疟疾反复发作 + 胁下摸到硬块 → 邪结成形

**病机（进 contraindications）**：疟久不愈，瘀血痰浊互结成「症瘕」；原文特意说「急治之」；现代可见于疟疾反复后的脾肿大。

### 新方剂 `biejia_jian_wan` 鳖甲煎丸

- needs：`nue_mu.yes`
- 二十三味的攻补兼施方：鳖甲软坚散结为君，配大黄、桃仁、䗪虫、蜣螂等破血逐瘀，又用人参、阿胶护正
- 做成小丸缓消（空心七丸、日三服），不是猛攻

## 4.3 瘅疟 —— 只出证候，原文无方

> 师曰：阴气孤绝，阳气独发，则热而少气烦冤，手足热而欲呕，名曰瘅疟，若但热不寒者，邪气内藏于心，外舍分肉之间，令人消铄脱肉。

### 新证候 `dan_nue` 瘅疟

| 路径 | 条件 |
|---|---|
| 1 | 只发热不发冷 + 手脚心发烫 |
| 2 | 只发热不发冷 + 明显消瘦 |

**本条只出证候，原文没有给方**，所以没有对应方剂节点。

**病机**：阳气独发、阴气孤绝（里热独盛、已伤阴）；「令人消铄脱肉」是热耗肌肉导致消瘦。

### 与温疟的鉴别（写进两条说明）

| | 瘅疟 | 温疟 |
|---|---|---|
| 共同点 | 但热不寒 | 身无寒但热 |
| 区别 | 少气烦冤、手足热、消瘦（里热伤阴） | 骨节疼烦、时呕（表邪未尽） |
| 方 | 原文无方 | 白虎加桂枝汤 |

## 4.4 温疟 + 白虎加桂枝汤

> 温疟者，其脉如平，身无寒但热，骨节疼烦，时呕，白虎加桂枝汤主之。

### 新证候 `wen_nue` 温疟

| 路径 | 条件 |
|---|---|
| 1 | 只发热不发冷 + 骨节疼烦 |
| 2 | 只发热不发冷 + 骨节疼烦 + 想呕 |

**按口径剔除**：「其脉如平」——原文自己都说脉没异常，本来就不该靠脉，也不入 needs。

- needs：`wen_nue.yes`
- 白虎汤清里热 + 桂枝一味兼解表通骨节；原文说服后「汗出愈」

## 4.5 牝疟 + 蜀漆散

- 已标注蜀漆有催吐作用、孕妇忌用

# 补漏：3.7 栝楼牡蛎散（批 4 漏掉的一条）

**这是本轮发现的一个真实缺口**：批 4 做了百合病 3.1~3.6 和 3.8，唯独把 3.7 跳过了。
原因是原文只写「百合病，渴不差者，**用后方主之**」，正文里没写方名，方名藏在后面的方剂段落里。

> 百合病，渴不差者，用后方主之。**栝楼牡蛎散方**：栝楼根、牡蛎等分，为细末，饮服方寸匕，日三服。

### 新方剂 `gualou_muli_san` 栝楼牡蛎散

- needs：`baihe_bing.yes + thirsty.yes + severe_thirst.yes`

**为什么加「渴得厉害」这个条件**：3.6 百合洗方和 3.7 栝楼牡蛎散在原文里是**先后两步**，不是二选一——
3.6 是「一月不解，变成渴」（刚变渴，走外洗透邪）；3.7 是「渴不差」（洗了还渴，津伤已深，必须内服生津）。

引擎记不住「洗过没效」，所以用「渴的程度」当代理：
- 只口渴 → 只出**百合洗方**
- 大烦渴、喝水不解 → 出百合洗方 **+ 栝楼牡蛎散**（后者是更强的内服选择）

实测已确认这两种情况分开。

## 关于「定时发冷发热」为什么必须单独建节点

库里已有 `alternating_cold_heat`（往来寒热），触发词是「发冷发热交替」「时冷时热」「寒热往来」。
疟疾的命门是**发作有固定时间**（一日一发、间日一发、三日一发），而少阳的往来寒热是**无定时**的。
这是临床鉴别的关键区别，不能合并，所以新建 `periodic_chill_fever`。

## 实测验证

| 场景 | 结果 |
|---|---|
| 只发热不发冷 + 手脚心发烫 + 消瘦 | ✓ 瘅疟 |
| 只发热不发冷 + 骨节疼烦 + 想呕 | ✓ 温疟 → ✓ 白虎加桂枝汤 |
| 每天定时发冷发热 + 冷多热少 | ✓ 牝疟 → ✓ 蜀漆散 |
| 隔一天定时发冷发热 + 胁下摸到硬块 | ✓ 疟母 → ✓ 鳖甲煎丸 |
| 百合病 + 只口渴 | ✓ 百合洗方 |
| 百合病 + 大烦渴喝水不解 | ✓ 百合洗方 + ✓ 栝楼牡蛎散 |
