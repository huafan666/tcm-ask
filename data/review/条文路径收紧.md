# 条文路径收紧（依据真实条文，不臆造条件）

**用户指示**：
1. 阴性条件可以增加，**但要符合真实情况**
2. 古文措辞覆盖不必做
3. 现有水平可接受，有些症状就是不好粗筛，**只要足够全面**；一轮评估耗时不算久

所以本轮只做一件事：**把「条文里本来就含多个要素」的单症状路径补回原文要求的组合**。
凡是**原文本身就只有那一个症状**的，一律不动——加条件就是篡改原文。

| 黄芪建中汤 | 金匮 6.15「虚劳里急、诸不足」 | `肚子拘急` | + `虚劳`（原文「虚劳」+「里急」两件事） |

| 赤石脂禹余粮汤 | 伤寒 159「下利不止，心下痞硬」 | `下利清谷` | + `久利`（原文强调「下利不止」） |
| 苦酒汤 | 伤寒 312「咽中伤，生疮，不能语言，声不出」 | `吞咽困难`、`喉咙紧缩` 两条单症状 | 收成 `喉咙紧缩 + 声音嘶哑`（声不出） |
| 风引汤 | 金匮 5.5「除热瘫痫」 | `抽搐` | + `发热`（原文是「**热**瘫痫」，抽搐只是「痫」） |
| 当归散 | 金匮 20.21「妇人妊娠，宜常服当归散」 | `怀孕` | **删除**（见下） |

### 当归散为什么单独处理

原文确实是「妊娠通用方」，但「只要怀孕 → 当归散」会让**任何孕妇**都命中，
和我自己写在它 contraindications 里的「**不主张无症状孕妇长期服药**」直接矛盾。
所以删掉那条单症状路径，只保留「妊娠 + 烦躁」「妊娠 + 没劲」两条（有具体不适才推荐）。

## 二、改了但**故意不改**的（重要）

### 小柴胡汤的 4 条单症状路径 —— 保留

伤寒 101 条明说：**「伤寒中风，有柴胡证，但见一证便是，不必悉具。」**
所以「往来寒热 / 胸胁苦满 / 默默不欲饮食 / 心烦喜呕」各成一条路径，是**忠实原文**，不是写松了。
改成组合反而是违背仲景本意。

## 四、发现两个需要你决定的问题

### 问题 1：13 个「药味/自造方」混在方剂层里

它们没有条文出处，但被标成了 `source: shanghanlun`（标注本身就不对），
而且都是**单症状成立**，所以病人只要沾上一个症状，这些就永远挂在候选里：

| 节点 | 单症状条件 |
|---|---|
| 补肾组合（泽泻+补骨脂，阳起石+细辛，乌药，炮附子） | 体力很差 / 足跟痛 / 双腿无力 / 小便数（**4 条**） |
| 牡蛎 | 钙化肿块 |
| 牡蛎 瓦楞子 | 乳房肿块 |
| 桂枝加炒麦芽 | 乳房肿块 |
| 覆盆子 | 精子稀少 |
| 厚朴 | 腹胀满 |
| 黄连黄芩 | 过敏红肿 |
| 连翘银花荆芥 | 皮肤痒 |
| 黄芪 党参 升麻 | 下坠 |
| 大黄 厚朴 枳实 | 轻度便秘 |
| **无需用药** | 吐脓血 ← **这个甚至不是方剂** |
| 分销汤 | 食谷欲呕（疑似「分消汤」错字） |
| 炙甘草 | 睡眠不好 |

**三个选项**：
- (a) 保留但打个标记（如 `advisory: true`），让问诊的候选方列表**不把它们算进去**，画布上照旧能查
- (b) 单独归一个 `kind`（如 `herb`），彻底和方剂分开
- (c) 删掉（其中「无需用药」我强烈建议删，它不是方剂）

### 问题 2：旋覆代赭汤有一条不在条文里的路径

```js
needs: [
  ['epigastric_lump_soft.yes', 'belching.yes'],   // ← 这条符合伤寒161「心下痞硬，噫气不除」
  ['wei_suan.yes']                                 // ← 这条不在条文里（原文没有「胃酸」）
]
```

它的 contraindications 里写着「如果是胃痛，可以加干姜和吴茱萸」——那是**加减法**，
不等于「胃酸 → 旋覆代赭汤」。这条看着像误加。要不要删？
