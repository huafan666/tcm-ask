## 白话版：百合病是什么

一个人得了一场热病之后，出现一种**浑身不对劲、但查不出明显毛病**的状态：

- 想吃，可真到吃的时候又吃不下
- 整天提不起劲，不想说话，也不想动
- 想躺下，躺下又躺不住
- 想出去走走，又觉得没劲走不动
- 有时候觉得冷，其实并不真冷；有时觉得热，量体温又不高
- 嘴里发苦，小便颜色深

原文说这种情况叫「**身形如和**」——人看着没大事，可就是不舒坦。

**治法大忌**：不能发汗、不能泻下、不能催吐。这三种治法一用，病情反而更重。

### 证候：`baihe_bing` 百合病（三条路径）

```
① 食欲时好时坏 + 提不起劲不想说话
② 想躺躺不住 + 想走走不动
③ 似冷非冷似热非热 + 嘴里发苦 + 小便黄
```

## 这轮撞出来的一个真误判（已修）

```
病人说「小便发黄」 → 竟然点亮了「身黄（黄疸）」
```

原因：`jaundice` 的触发词里有一个**裸的「发黄」**——小便发黄、指甲发黄都会撞上。

修法：去掉裸「发黄」，换成具体的「皮肤发黄／身上发黄／眼睛发黄／眼白发黄」，
并把标题从「身黄/发黄」改成「皮肤眼睛发黄」（更清楚）。
同时给 `dark_urine` 补了「小便发黄」等说法，否则病人这么说反而没人接。

**这类"裸词过宽"是这套库最大的隐患**——像「发黄」「不安」「不想动」这种两字词，
很容易把无关症状点亮。后面整理时要专门盯这一点。
