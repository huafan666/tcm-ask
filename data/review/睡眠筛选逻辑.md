# 睡眠症状的筛选逻辑（检查报告 + 重构）

**用户要求**：睡眠这部分得检查一下，告诉我现在的筛选逻辑。像睡眠不好相关的东西，**必须要初筛**。
**另一项**：胃酸是现代人的说法，改到符合临床即可。

---

## 一、检查发现的三个问题（都是实测出来的）

### 问题 1：「睡眠不好」一说就定方 —— 最严重

实测：

```
输入「睡眠不好」
  ✓ 睡眠不好 (shuimianbuhao)
  ✓ 睡眠异常 (sleep_any)
  ✓ 炙甘草 (zhigancao)     ← 直接点亮了一个方剂
```

原因：`zhigancao`（单味炙甘草）的 needs 就是 `['shuimianbuhao.yes']`。
病人只需要说「睡眠不好」这三个字，方剂就成立。

而且它还牵出一个证候：

```js
ganxuebuzu（肝血不足）的第三条路径 = ['shuimianbuhao.yes','tuofa.yes','jaundice.yes']
```

「睡眠不好 + 脱发 + 皮肤眼白发黄」→ 肝血不足。用「睡眠不好」这么笼统的词当条件不合适。

### 问题 2：睡眠只有一个笼统节点，没有分型

重构前的睡眠相关节点：

| 节点 | 语义 | 问题 |
|---|---|---|
| `sleepy` | 白天老想睡（多眠） | ✅ 清楚 |
| `shuimianbuhao` | 睡眠不好 | ❌ **笼统**，trigger 里混着「睡眠浅」「容易醒」「睡不实」 |
| `vex_insomnia` | 虚烦不得眠（心里烦得睡不着） | ✅ 清楚 |
| `duomeng` | 多梦 | ✅ 清楚 |
| `restless_lying` | 想躺躺不住 | ✅ 清楚 |

**缺的是最基础的分型**：入睡困难 / 睡着了容易醒 / 睡眠浅。
这三种在临床上处理完全不同（入睡难多与神志有关、易醒多与心脾有关），
却被 `shuimianbuhao` 一个节点一锅端了。

### 问题 3：筛选组存在但用不上

`sleep_any`（睡眠异常）这个组当时就有，但：
- trigger 里放了**单字**「睡」「眠」，过宽
- **没有任何方剂引用它**（本来就不该被引用，但也没起到粗筛作用）
- 更关键：病人说「睡眠不好」时，`sleep_any` 虽然成立了，但问诊**不会往下细化**，而是跑去问腹部、寒冷这些无关大类

## 二、重构后的筛选逻辑（现在的样子）

### 三层结构

```
① 症状筛选组（粗筛）
   sleep_any 睡眠异常
        │  trigger：睡眠/睡不好/睡不着/失眠/不寐/多梦/嗜睡/老想睡/入睡/睡不实/容易醒
        │  （已去掉单字「睡」「眠」）
        ↓  任一组员成立 ⇒ 组成立；组员被否定不影响组
② 笼统描述（必须细化，不能直接用于推理）
   shuimianbuhao 睡眠不好（笼统说法）   ← 标了 vague: true
        │  病人只会说这一句，说了 ≠ 说清是哪一种
        ↓
③ 具体分型（原子症状，方剂只依赖这一层）
   ├ insomnia_onset   入睡困难（新建）
   ├ frequent_waking  睡着了容易醒（新建）
   ├ light_sleep      睡眠浅（新建）
   ├ duomeng          多梦
   ├ vex_insomnia     虚烦不得眠（心里烦得睡不着）
   ├ sleepy           多眠睡（白天老想睡）
   ├ restless_lying   想躺躺不住
   └ dahan            打鼾
```

### 关键机制：`vague` 标记

`shuimianbuhao` 本身也是 `sleep_any` 的子症状。如果按「组里已有子症状确定就不细化」的规则，
它自己就把这条判断满足了，永远细化不下去。

所以给它加了 `vague: true`（笼统描述标记）：

- 问诊判断「这个组要不要往下细化」时，**笼统描述不算「已经说清楚」**
- 于是病人说「睡眠不好」→ 问诊会立刻问：入睡困难 → 容易醒 → 睡眠浅 → 虚烦不得眠 → 多眠睡 → 多梦

实测（重构后）：

```
输入「睡眠不好」
  Q1 入睡困难
  Q2 睡着了容易醒
  Q3 睡眠浅
  Q4 虚烦不得眠
  Q5 多眠睡
  Q6 多梦
```

**不再跑去问腹部、寒冷、大便这些无关大类了。** 每个聚焦组最多问 6 个细化问题，防止问崩。

### 解除了「睡眠不好 → 方剂/证候」的直接依赖

| 节点 | 原来 | 改成 | 理由 |
|---|---|---|---|
| `zhigancao` 炙甘草 | `['睡眠不好']` | `['心悸']` | 炙甘草的用处是补气强心（它自己的说明就写着「可以强心」），**不治睡眠不好** |
| `ganxuebuzu` 肝血不足 | 有一条 `['睡眠不好','脱发','黄疸']` | `['脱发','入睡困难']` / `['脱发','多梦']` / `['脱发','面色苍白']` | 睡眠那项改成具体类型 |

## 三、胃酸 → 反酸/烧心

按你说的「胃酸是现代人的说法，改到符合临床」：

| 项 | 改前 | 改后 |
|---|---|---|
| 节点标题 | 胃酸 | **反酸/烧心** |
| trigger | 胃酸、酸水、反酸 | 胃酸、酸水、反酸、**烧心、反胃酸、胸口烧得慌、胃里往上返酸** |
| 旋覆代赭汤路径 | `['wei_suan.yes']`（单反酸，不在条文里） | `['wei_suan.yes','belching.yes']`（**反酸 + 嗳气**） |

旋覆代赭汤治的是胃虚气逆，诊断要点是原文那句「心下痞硬，**噫气不除**」，
所以临床上「反酸 + 嗳气」才是它的典型组合，单有反酸不足以定本方。

实测：`反酸，嗳气` → ✓ 旋覆代赭汤

## 四、关于那 13 个药味/自造方（你说没关系，我不动）

按你的意思，方剂本身就是药物组合，单味药恰好符合条件也没问题，所以：

- **不动它们**，也不删「无需用药」（虽然它名字不像方剂，但那是你录的）
- 唯一的处理是把「睡眠不好」这类**笼统条件**从方剂依赖里摘掉（已做）
