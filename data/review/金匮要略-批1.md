## 2.1 剛痙

**原文**：太陽病，發熱無汗，反惡寒者，名曰剛痙。
**简体**：太阳病，发热无汗，反恶寒者，名曰刚痉。

| 项 | 内容 |
|---|---|
| 病位 | 太阳 |
| 阳性 | 发热、无汗、恶寒 |
| 阴性 | 无（「反」是语气，不是否定） |
| 舌脉 | 未提及 |
| 结论 | 刚痉（证候） |

**三元组（1 条）**

```
1. fever.yes + no_sweat.yes + cold_aversion.yes —— 太阳 —— 刚痉
```

**节点映射**：`fever`(发热) ✓ `no_sweat`(无汗) ✓ `cold_aversion`(恶寒) ✓
**待建**：证候 `gang_jing` 刚痉（summary）

## 2.2 柔痙

**简体**：太阳病，发热汗出，而不恶寒，名曰柔痉。

| 项 | 内容 |
|---|---|

| 结论 | 柔痉 |


**节点映射**：`fever` ✓ `sweat`(汗出，trigger 含「汗出」) ✓ `cold_aversion.no` ✓（引擎已能识别「不恶寒」）
**待建**：证候 `rou_jing` 柔痉（summary）

## 2.7 痙病主证

**原文**：病者身熱足寒，頸項強急，惡寒，時頭熱，面赤，目赤，獨頭動搖，卒口噤，背反張者，痙病也。若發其汗者，寒濕相得，其表益虛，即惡寒甚。發其汗已，其脈如蛇。
**简体**：病者身热足寒，颈项强急，恶寒，时头热，面赤，目赤，独头动摇，卒口噤，背反张者，痉病也。若发其汗者，寒湿相得，其表益虚，即恶寒甚。发其汗已，其脉如蛇。

| 项 | 内容 |
|---|---|
| 阳性 | 身热、足寒、颈项强急、恶寒、时头热、面赤、目赤、独头动摇、口噤、背反张 |
| 禁忌（后半句） | 误汗则表益虚、恶寒更甚「发其汗已，其脉如蛇」 |

**三元组（3 条 OR，取最能定位的几组）**

```
1. bei_fan_zhang.yes + kou_jin.yes            —— 痉病（背反张 + 口噤 = 最硬的两个体征）
2. neck_stiff_pain.yes + du_tou_dong_yao.yes  —— 痉病（颈项强急 + 独头动摇）
3. shen_re_zu_han.yes + mian_chi.yes          —— 痉病（身热足寒 + 面赤）
```

**节点映射**：`neck_stiff_pain` ✓ `cold_aversion` ✓
**待建（6 个症状节点）**：`shen_re_zu_han` 身热足寒、`tou_re` 时头热、`mian_chi` 面赤、`mu_chi` 目赤、`du_tou_dong_yao` 独头动摇、`kou_jin` 口噤、`bei_fan_zhang` 背反张（共 7 个）

> ⚠ 三个已有节点语义**不能**硬套：
> - 面赤：现有 `inner_cold_outer_heat` 是「里寒外热(面赤)」，那是少阴格阳证，跟痉病面赤不是一回事 → 必须新建
> - 足寒：现有 `cold_extremities` 是「手足逆冷」，痉病是「足寒而身热」，部位与病机都不同 → 建议新建或给它加「足寒」关键词后单列
> - 身热：现有 `fever`(发热) / `zijue_shenre`(自觉身热) / `burning`(身体灼热) 三个都沾边，需要你定用哪个

## 2.11 栝蔞桂枝湯（痉病有汗）

|---|---|

```
1. neck_stiff_pain.yes + sweat.yes + fever.yes        —— 柔痉 —— 栝蒌桂枝汤
2. neck_stiff_pain.yes + sweat.yes + pulse_sunken_slow.yes —— 柔痉 —— 栝蒌桂枝汤
```

**节点映射**：`neck_stiff_pain` ✓ `sweat` ✓ `fever` ✓
