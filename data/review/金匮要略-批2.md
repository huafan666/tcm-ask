## 2.23 桂枝附子汤 / 去桂加白术汤（风湿在表·表阳虚）

> 伤寒八九日，风湿相搏，身体疼烦，不能自转侧，不呕不渴，脉浮虚而涩者，桂枝附子汤主之；
> 若大便坚，小便自利者，去桂加白术汤主之。

| 要素 | 原文 | 节点 |
|---|---|---|
| 身体疼烦、不能自转侧 | ✓ | `body_ache_stiff` ✓ |
| **不呕** | 阴性 | `vomiting.no` ✓ |
| **不渴** | 阴性 | `thirsty.no` ✓ |
| **大便坚** | ✓（去桂加白术的鉴别） | **NEW** `hard_stool` |
| 小便自利 | ✓ | `easy_urination` ✓ |
| 脉浮虚而涩 | 脉象 | 不做 |

**三元组（桂枝附子汤）**

```
旧  身体疼烦不能转侧                                    ← 1 个要素，太松（建议替换）
新T1 身体疼烦不能转侧 + 不呕 + 不渴                      —— 风湿在表·表阳虚 —— 桂枝附子汤
新T2 身体疼烦不能转侧 + 不渴                            —— 同上（简化）—— 桂枝附子汤
```

**三元组（去桂加白术汤）**

```
旧  身体疼烦不能转侧 + 小便自利
新T1 身体疼烦不能转侧 + 不呕 + 不渴 + 大便坚            —— 风湿兼里湿（湿胜于风）—— 去桂加白术汤
```

> **这是这批最值钱的一处**：桂枝附子汤与去桂加白术汤在原文里只差「大便坚／不坚」。
> 现在库里两条只差「小便自利」，抓不住原文的鉴别点。补 `hard_stool` 才能真正分开。

**现代佐证**：静息后起身僵硬、变换体位疼痛加重、无消化道症状与脱水表现。

**待建**：症状 `hard_stool`（大便坚 / 大便干结 / 拉出来很硬 / 一粒一粒）

## 2.26 白虎加人参汤（暍病 / 中暍）— 新增一条与伤寒路径并列的路径

> 太阳中热者，暍是也。汗出恶寒，身热而渴，白虎加人参汤主之。

| 要素 | 原文 | 节点 |
|---|---|---|
| 汗出 | ✓ | `sweat` ✓ |
| 恶寒 | ✓ | `cold_aversion` ✓ |
| 身热 | ✓ | `fever` ✓ |
| 渴 | ✓ | `thirsty` ✓ |

**三元组**

```
现有  大烦渴 + 不恶寒（伤寒第26条：纯热证）
新T1  汗出 + 恶寒 + 身热 + 渴        —— 暑热伤津（暍病）—— 白虎加人参汤
```

> ⚠ 这条要特别看一下：现有路径要求 **不恶寒**，而暍病是**恶寒**。
> 两条路径极性相反，但引擎规则是「任一路径全部满足就成立」，
> 所以「汗出+恶寒+身热+渴」能独立命中暍病那条，不会互相打架。
> 风险在于：**太阳表证汗出恶寒而口渴的人**（如桂枝汤证兼渴）可能被这条误判成暍病。
> 兜底做法：把 `sweat.yes` 换成更严的「大汗」，或再加一个「不呕」——**要你定**。

**现代佐证**：高温/暴晒暴露史、大汗、口渴、心率增快、尿少色深——中暑（热射病）早期的经典四项。
