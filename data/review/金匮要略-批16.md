## 六种水 + 气分（本篇核心）

| 证候 | 关键条件 | 原文依据 | 鉴别要点 |
|---|---|---|---|
| `feng_shui` **风水** | 水肿 + **怕风** | 脉浮，骨节疼痛，恶风 | 有外感表证 |
| `pi_shui` **皮水** | 水肿 + **不怕风** / 水肿 + 不渴 | 胕肿按之没指，不恶风，腹如鼓，不渴 | 与风水就差「恶风」二字 |
| `zheng_shui` **正水** | 水肿 + **喘** | 脉沉迟，外证自喘 | 水气上凌于肺所以喘 |
| `shi_shui` **石水** | 腹满 + 水肿 + **不喘** | 脉自沉，腹满不喘 | 与正水就差「喘」字 |
| `huang_han` **黄汗** | **汗黄色** + 身肿 | 汗沾衣，色正黄如柏汁 | 黄汗是「汗黄」，黄疸是「身目尿黄」 |
| `qi_fen` **气分** | 心口下盘大硬结 | 心下坚，大如盘，边如旋杯 | 水饮结聚成块 |

**这几组鉴别是这一篇的精华，都写进说明了**：
- 风水 vs 皮水：**恶风 / 不恶风**
- 正水 vs 石水：**喘 / 不喘**
- 黄汗 vs 黄疸：**汗黄 / 身目尿黄**

**安全提示**：风水加了「眼泡肿+血尿+血压高要警惕急性肾炎查尿常规」，
正水加了「全身水肿+喘+尿少要查心肾功能」，石水加了「腹水要警惕肝硬化」，
黄汗加了「汗黄须先排除肝胆疾病」。

## 方剂 10 个新建 + 2 条追加

| 方 | 关键条件 | 要点 |
|---|---|---|
| `yuebi_jia_zhu_tang` 越婢加术汤 | 水肿 + 小便不利 | 越婢汤 + 白术，表里分消 |
| `yuebi_tang` 越婢汤 | 一身悉肿 + 怕风 + **出汗** | 汗出还照用麻黄，因为要宣肺利水 |
| `fangji_fuling_tang` 防己茯苓汤 | 四肢肿 + **肌肉聂聂动** | 「聂聂动」是水在皮中的特异指征 |
| `gancao_mahuang_tang` 甘草麻黄汤 | 水肿 + **无汗** | 两味，发汗极简方 |
| `mahuang_fuzi_tang` 麻黄附子汤 | 水肿 + 四肢凉 | 有附子针对阳虚，与甘草麻黄汤区别在此 |
| `xingzi_tang` 杏子汤 | 水肿 + 怕风 + 无汗 | ⚠ **原方已佚**，组成不确定，已明确标注不可照方抓药 |
| `qishao_guijiu_tang` 芪芍桂酒汤 | 黄汗 + 身肿 | 加苦酒（醋）敛汗；服后心烦是正常反应 |
| `guizhi_jia_huangqi_tang` 桂枝加黄芪汤 | **腰以上出汗腰以下无汗** + 身重 | 表虚阳气不足 |
| `guizhi_qu_shaoyao_jia_maxin_fuzi_tang` 桂枝去芍药加麻辛附子汤 | 盘大硬结 + 四肢凉 | **偏阳虚寒凝（虚）** |
| `zhizhu_tang` 枳术汤 | 盘大硬结 + 腹胀 | **偏气滞水停（实）**，两味，枳实 > 白术（重在行气） |

**气分两方一虚一实**：桂枝去芍药加麻辛附子汤（阳虚寒凝）vs 枳术汤（气滞水停），
与第九篇「枳实薤白桂枝汤 vs 人参汤」、第十二篇「诸方并列」是同一类对照结构。

> 「为什么去芍药」也写进说明了：芍药酸收敛阴，会妨碍通阳散寒。

既有方剂追加：`fangji_huangqi_tang`（14.27 风水水肿）、`puhui_san`（14.32 厥而皮水）
